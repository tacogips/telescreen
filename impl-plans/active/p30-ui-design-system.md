## Intent and Context

The owner approved a Sentry-pattern UI (design-ui-sentry.md). This first-wave plan
delivers everything the page plans (p12, p13, p14) build on: design tokens with light and
dark themes, the component library, the application shell (primary rail, secondary panel,
TopBar slots, mobile layout, shortcuts), self-hosted fonts, three npm dependencies and the
headless screenshot script. The page plans start only after this plan lands, because the
lockfile changes here.

Run in parallel with `p31-ui-mock-api`, which owns `src/web/src/api/**` and edits page
files. You never touch `src/web/src/api/**` or `src/web/src/pages/**`.

## Non-goals

- No page markup changes (pages belong to p31 in wave B1 and p12/p13/p14 in wave B2).
- No API client changes, no mock data, no backend changes, no Python changes.
- No copied Sentry code, CSS, icons, illustrations, names or brand colors (no `#7553FF`,
  no pink/lime set). Icons come only from `lucide-solid`.
- No CSS-in-JS runtime, no chart library, no component library dependency.

## Deliverables

### Styles (`src/web/src/styles/`)

- `tokens.css`: every token of design section 1 as CSS custom properties on `:root`
  (light) and `[data-theme="dark"]`, plus `@media (prefers-color-scheme: dark)` applying
  the dark values to `:root:not([data-theme="light"])`. Use the exact hex values in the
  design table. Include typography (with the Japanese system fallbacks), spacing,
  radius, ledge shadows, motion (durations, `snap`, `smooth`, `enter`), z-index,
  breakpoint and container size tokens. Under `prefers-reduced-motion: reduce` set all
  duration tokens to `0ms`.
- `fonts.css`: `@font-face` for Rubik 400/500 and Roboto Mono 400/500 pointing at
  `/fonts/...woff2`, `font-display: swap`.
- `base.css`: box-sizing, body font/colour/background from tokens, focus-visible ring
  (2px `--accent`), `.visually-hidden`, tabular numbers utility, link colour.
- Replace `app.css` content with imports of the three files above (keep the file name;
  `main.tsx` imports it). Remove p07 legacy selectors that no longer match markup.

### Theme

- `components/shell/theme.ts`: `export type ThemeChoice = "system" | "light" | "dark"`,
  `getTheme(): ThemeChoice`, `setTheme(choice: ThemeChoice): void`, persisted in
  `localStorage` key `telescreen.theme`; `applyTheme()` sets or removes `data-theme` on
  `document.documentElement`. Called once from `main.tsx` before render. p14 Settings
  imports `getTheme`/`setTheme` (contract: names and the key are fixed).

### Components (`src/web/src/components/ui/`, one `.tsx` + one `.css` per component)

Implement each component of design section 2 with its exact sizes, variants and aria
behavior: `Button` (props `variant: "default" | "primary" | "danger" | "transparent" |
"link"`, `size: "md" | "sm" | "xs" | "zero"`, `busy?`, plus native button props),
`SplitButton`, `Tag` (`variant: "muted" | "info" | "danger" | "warning" | "success"`),
`StatusIndicator`, `SeverityBar`, `PriorityBadge` (read-only, `level: "high" | "medium" |
"low"`), `ProgressMarker` (`step: 0 | 1 | 2 | 3 | 4`), `SearchQueryBuilder`,
`PageFilterBar`, `SortSelect`, `Panel`/`PanelHeader`/`PanelItem`, `Table`, `Pagination`,
`Drawer`, `FoldSection`, `Timeline`, `Redacted`, `EmptyState`, `Placeholder`,
`MiniBarChart`, `Toast` (+ `showToast(message, variant)`), `Tooltip`, `Menu`, `Select`,
`Hovercard`. Export all from `components/ui/index.ts`.

Contracts used by page plans (pin these signatures):

- `SearchQueryBuilder` props: `{ value: string; onChange(value: string): void;
  keys: readonly QueryKeySpec[]; placeholder?: string }` where
  `QueryKeySpec = { key: string; values?: readonly string[]; description: string }`.
  Export pure helpers `parseQuery(text: string, keys: readonly QueryKeySpec[]):
  QueryToken[]` and `serializeTokens(tokens: readonly QueryToken[]): string` with
  `QueryToken = { kind: "filter"; key: string; value: string; negated: boolean; valid:
  boolean; reason?: string } | { kind: "text"; value: string }`. A token is invalid when
  the key is unknown, the value uses `!`, `*`, `[`, `,`, `>`, `<`, or the key repeats.
  The builder never drops user text; invalid tokens render with the danger style and a
  tooltip naming the supported keys. Mapping tokens to API params is the page's job.
- `MiniBarChart` props: `{ values: readonly number[]; total?: readonly number[];
  label: string; height?: number }` (inline SVG, `role="img"`, `aria-label` = label).
- `Redacted` props: `{ text: string; ruleClass?: string }`. It splits `text` into plain
  and masked segments using the Masker output forms (design-masking.md Masking policy):
  runs of 3+ `*` optionally followed by `[N]`, `[REDACTED ...]` markers including
  `[ADDRESS REDACTED]`, and `**** **** **** 1234`. Masked segments get the danger-muted
  mono style and a tooltip "Masked (rule: <ruleClass>)". Export the pure splitter
  `splitMasked(text: string): { masked: boolean; text: string }[]`.
- `FoldSection` props: `{ id: string; title: string; children }`; state persisted under
  `localStorage` key `telescreen.fold.<id>`; opens when `location.hash === "#" + id`.
- `Drawer` props: `{ open: boolean; onClose(): void; title: string; mode?: "blocking" |
  "passive"; children }`; width persisted under `telescreen.drawerWidth`.

### Shell (`src/web/src/components/shell/`)

- `AppShell.tsx` (replaces `Layout`): skip link "Skip to main content" -> `#main`,
  `PrimaryRail`, `SecondaryPanel`, `TopBar`, `<main id="main">`, global `Toast` region,
  a "Mock data" `Tag` in the TopBar when `import.meta.env.VITE_TELESCREEN_MOCK === "1"`
  (read the env directly; do not import from `api/`).
- `PrimaryRail.tsx`: items per design section 3 (Issues, Search, Workflows, Police,
  Collectors, Escalation, Audit, Assistant, Settings) with lucide icons; `/runs` routes
  mark Workflows active; `aria-current="location"` on the active item.
- `SecondaryPanel.tsx`: resizable 150-450px (default 190, persisted
  `telescreen.panelWidth`), collapsible (`telescreen.panelCollapsed`), hover peek when
  collapsed. Content per area from `nav.ts`:
  - Issues: Feed (`/issues`), By source (one link per source `slack, gdrive, gdocs,
    gsheets, github, custom, police` -> `/issues?query=source:<s>`), By rule (one link per
    rule class `credential, token, private_key, password, payment_card, national_id,
    email, phone, address` -> `/issues?query=rule:<c>`), Views (read
    `localStorage["telescreen.issueViews"]`, JSON array of `{id, name, query, sort,
    starred}`; tolerate missing/invalid JSON by showing none; link
    `/issues?query=<encoded>&sort=<sort>`). Re-read the key on the `storage` event and on
    a custom `telescreen:issue-views` window event (p12 dispatches it after saving).
  - Workflows: Workflows (`/workflows`), Runs (`/runs`). Other areas: their single link.
- `TopBar.tsx`: sticky 53px; `TopBar.Slot` component with `name: "title" | "actions"`
  rendering children into the bar through Solid `Portal` targets; the `title` slot
  content is wrapped in the page's single `<h1>`. Buttons "Ask Assistant" (navigates to
  `/assistant?context=<encoded current path>`) and a search button (navigates to
  `/search`).
- Mobile (< 992px): rail and panel collapse into a top menu button opening a slide-in
  panel.
- `shortcuts.ts`: `mod+k` command palette (navigate to any area; Escape closes), `mod+b`
  toggle panel collapse, `mod+/` same as "Ask Assistant". `mod` = Meta on macOS, Ctrl
  elsewhere. Ignore shortcuts while focus is in a text input except `mod+k`.

## Key Pitfalls

- Tokens must be the Telescreen palette from the design table; reviewers grep for
  `#7553FF` and Sentry names (`Sentry`, `Scraps`, `Seer`) in your paths: zero hits.
- The Button lift must be pure CSS (`::before` edge + `::after` surface, `transform` on
  the label); `:active`, `[aria-expanded="true"]`, `:disabled` and busy remove the lift.
- Never put `innerHTML` anywhere. `Redacted` builds spans from text segments.
- `TopBar.Slot` must work when a page renders before the TopBar target mounts (create the
  target nodes in `AppShell` before children render, or fall back to inline rendering).
- `AreaPage` and `AREAS` are imported by `shell.test.tsx` and by pages; keep their
  exported names and shapes (adding `group` is the only change).
- Keep every `.tsx` file under 400 lines.
- Hash drift: p31 edits `src/web/src/api/**` and `src/web/src/pages/**` at the same time;
  never edit those, and do not "fix" their typecheck errors.

## Tests (vitest, next to each file, `*.test.tsx`)

- Button: renders `aria-busy` and is disabled when `busy`; `variant="primary"` class.
- SearchQueryBuilder helpers: `parseQuery("is:unresolved foo", keys)` -> one valid filter
  + text; `!is:resolved`, `severity:[high, medium]`, `times_seen:>5`, `collector:x` ->
  invalid with reason; duplicate key -> second invalid; `serializeTokens(parseQuery(s))`
  round-trips `s` for valid input; keyboard: Backspace on empty input focuses the last
  pill; "Remove filter: is" button removes it.
- `splitMasked`: `ghp_****************[40]` -> one masked segment after `ghp_`;
  `[ADDRESS REDACTED]`, `**** **** **** 1111`, `-----BEGIN PRIVATE KEY----- [REDACTED
  1675 chars]` produce masked segments; plain text -> one unmasked segment.
- FoldSection persists collapse state; Drawer closes on Escape and traps focus.
- MiniBarChart renders N bars and the aria label.
- StatusBadge maps statuses to the variants above.
- Theme: `setTheme("dark")` sets `data-theme="dark"` and the storage key; `"system"`
  removes the attribute.
- Shell (`shell.test.tsx`, update): rail renders the nine labels in order; `/runs` marks
  Workflows `aria-current="location"`; skip link targets `#main`; `/chat` redirects to
  `/assistant`; Issues panel lists saved views from `telescreen.issueViews` and survives
  invalid JSON; `mod+b` toggles collapse; keep the existing AreaPage and apiFetch tests.
